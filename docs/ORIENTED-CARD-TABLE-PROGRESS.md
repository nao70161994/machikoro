## 実装の第一段階（未コミット）

- CardTableLayoutを新設。各席のnative寸法を測り、0/180/±90度の回転後footprintを確保して中央市場を囲む絶対配置。2/3/4、5〜10の同辺複数slotを設計。手番で物理席が入れ替わらず、self不明は席0を視点基準にする。observerの自分ラベルとは区別する。
- CardTableCameraをquarter-turn行列/逆行列へ変更。viewportはnative scroll、zoom/pinch/resize/正面focus/戻るで共通座標変換を使う。戻るは元のmodel中心・倍率・角度・overview状態を保存復元。HUD/説明は回転しない。
- 所有カードのクリックは既存詳細を1回で開きつつ、背景の対象席も正面化。二段階tapを強制しない。ドラッグ後の誤クリック抑止を優先。
- 既存施設アートとルールの正本を再利用し、カードを160×124の横長書式へ。旧カード卓の密度ごとのCSSgrid上書き群を整理（約500行を削除）。新規JSはscript順/型global/ESLint/SWへ登録。未公開更新版cache v341。
- カメラ変更時は古いcoinflight/発動タグを終了し、誤った場所へ飛ばさない。市場がdialogへ移動中は卓の占有寸法を保持し、購入後のcard focusは配置更新後に行う。この追加guardは最初のsmoke成功後に実装したので、次の操作検証が必要。
