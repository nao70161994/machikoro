# ad5 実UI対戦の静止画レビュー

## 対象と確認方法

`artifacts/ui-playthrough-ad5/{320,1440}/` の各7 PNGを列挙し、そのうち各幅の次の5枚、計10枚を目視した。

- `ui-playthrough-start.png`
- `ui-playthrough-midgame.png`
- `ui-playthrough-late-game.png`
- `ui-playthrough-special-effect.png`
- `ui-playthrough-winner.png`

同じディレクトリにある `ui-playthrough-first-roll.png` と `ui-playthrough-first-build.png` は今回の追加レビューでは目視対象外。各PNGは `ui-playthrough-人間席の実UI操作とCPU弱で開始から結果まで進める-mobile-webkit/` 配下にある。

提供された実行条件は、自動ブラウザで人間席の実UI操作と弱CPUを使った、乱数固定なしの対戦。これは物理スマートフォンでの手動確認ではない。画像を閲覧しただけで、コード変更、追加ブラウザ起動、追加テストは行っていない。

## 判定

目視した画像には、主要操作を読めなくする重大な重なり、所有者名と市場の明確な取り違え、勝利文の欠落は見当たらない。320幅でも上部の所持金・目標数と下部のロール／ターン終了操作は読める。赤／黄の区切りと市場の破線枠が、対戦相手・市場・自分の区分を維持している。1440幅では終盤の施設群とランドマークが盤内に収まり、勝利画面の順位、再戦、共有、タイトル操作も表示されている。

## 残る具体的な課題

- **中程度・320幅の終盤の判読性**：全体縮小でカード名・所有枚数・市場価格と在庫が非常に小さい。全体図として所有配置を追えても、細部を全体表示だけで判断するのは厳しい。拡大操作は表示されているが、その実効性はこの静止画では未確認。
- **軽度・320幅の名前との距離**：中盤と終盤の自分の名前札が施設群の右側・下側へ回り込む。区切りと青色で対応は追えるものの、名前が常にカード群の上にある配置より対応を探す負担がある。別所有者と重なる状態は見当たらない。
- **軽度・320幅の特殊効果の改行**：改築屋の説明は「ランドマーク」や「コイン」の途中で折り返す。選択肢の駅・ショッピングモール・港と報酬は読め、操作を遮る重なりはないが、文章の読みやすさに改善余地がある。
- **軽度・勝利画面の改行と画面外情報**：320幅・1440幅とも「プレイヤー1」「の勝利！」の2行で、勝者と結果は明瞭。320幅の補足文は末尾「た。」だけが次行となり、見栄えが不自然。320幅では順位の続きや共有／タイトル操作が画像下端より先にあるため、到達性は静止画から確認できない。
- **軽度・1440幅の特殊効果の被覆**：ITベンチャーの選択パネルが自分の右側の施設と通常の下部操作の一部を覆う。パネル内の積立／スキップは露出し、HUDと市場は保たれている。選択中のパネルとして重大な操作妨害は見当たらない。

## 評価の限界

静止画は、スクロールと拡大の操作性、タップ領域、入力応答、アニメーションの滑らかさ、送金や発動を時間順に理解できるか、フレーム落ち、物理端末での表示を証明しない。幅ごとに別のランダム対戦であり、同じアニメーション時刻のA/Bではない。対戦完走という実行結果と、ここでの静止画の可読性評価は分けて扱う。
