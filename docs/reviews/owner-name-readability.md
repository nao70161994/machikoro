# 狭幅の所属名を読むための表示整理

対象はにぎわい広場のscreen-space所属ラベル。通常の名前はHUDと同じ名前だけを表示し、重複する名前だけ席番号を残す。空名は席番号へfallbackする。完全な席番号・名前はtitle/aria、所属indexと色は従来のまま。pointer-events:noneのtitleをタッチ操作の全文確認手段とは数えない。

320×568、施設14/16種類・完成ランドマーク5/2枚の人間2席fixture。前は743a9b5c、後は作業候補。Termux Chromiumの別contextを順次実行した比較で、自然対局・物理スマートフォン確認とは区別する。

- 卓312×392px、俯瞰倍率0.205、施設最小幅32.785px、ラベル文字12pxは同じ。
- 自分の96pxラベルは接頭辞で名前末尾が切れていたが、変更後は名前全文を読める。
- 相手ラベルは118→96pxで全文を維持。正本は不変。
- カードや文字を縮めず、冗長な接頭辞の幅を名前へ回す変更。

## 検証と制約

既存の320/390×844の市場境界assert、4人390/844の全文・非重複assertを維持。2人の既存caseへ320×568の全文・所属・title/aria・非重複・卓内収容と同名2席の識別を追加した。3件のブラウザ検証成功、最終の同名確認を含む1件も成功。ケース数は増やしていない。

独立した画像/静的レビューは採用を支持。名前が施設群末尾へ配置される場合は残る。今回の修正を、すべての構成で市場側へ名前を置く保証や、商用品質への到達証明とは扱わない。固定WebKitの確認は後続CIで行う。
