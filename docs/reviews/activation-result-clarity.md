# 発動結果の読み取りと所有者ラベルの保護

## 原因と変更

公開32388babのRelease41681932441、集中41681966907、Nightly41681963037は、320pxの発動札が街3の所有者名を覆う同じ製品不具合を初回・retryとも検出した。発動元付近だけでは空き場所を見つけられず、従来のアート除去条件も所有者被覆を含まなかった。

発動元付近を優先したうえで、必要な場合だけ卓の空き位置も探索する。所有者名が覆われる場合もアートなし表示へ切り替える。元施設と所有者の強調は維持する。収支は通常22pxで強調し、単位は11px、極端に大きな整数は12px・単位別行へ縮小して全桁を維持する。Gridの最小幅を明示し、金額が内部トラックを押し広げる不具合も修正する。衝突回避でアートを後から外した場合も金額を再計測し、最終サイズで配置する。

進捗名は、所有者×施設ごとの結果数であることに合わせ「施設結果」に変更した。600ms表示、700ms間隔、最大500ms待機、世代/再生guard、Undo等の再生抑止、Reduced Motionの静止1件は変更しない。ゲーム状態・ルール・オンライン経路は変更しない。

境界テストは表示専用fixtureであり、通常の対局で最大整数が発生した証拠ではない。既存の所有者/発動元非被覆、送金フレーム期限、opacity、再生条件のassertは維持する。強制クリックは追加しない。

## 体験評価と残る差

[公式サイト](https://m-machikoro.g-rounding.com/)と公式映像は、大きい主役カード、卓面の奥行き、プレイヤー反応、収益の強調を一体で見せている。本変更は既存施設アートと金額の読み取りを改善するが、公式と同等の華やかさ・連鎖の体感を証明するものではない。空き位置への移動時に発動元を追いやすいか、短い表示時間で読めるかは通常速度の再レビュー対象に残す。物理スマートフォン未確認。
