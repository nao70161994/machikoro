# ゲーム改善の実装判断

## 2026-08: おすすめ案の実装状況

実装済み:

- 現在の手番・フェーズ・次の操作をゲーム画面へ常設表示する。
- オンラインの接続状態、応答待ち、遅延、再接続、同期中を可視化する。
- 5人以上では非手番かつ自分以外の盤面を折り畳み、手番と自分は展開状態を保つ。
- 待機室から確認付きで退出し、同じルームIDで再参加しやすい状態へ戻す。
- ローカル対戦は同じ人数・プレイヤー設定で再戦できる。
- 勝利画面で正確な最終盤面と、端末が観測した直近ログを区別して振り返る。
- CPUが実際に選択した行動を表示する。判断根拠を取得できない箇所では因果を推測しない。
- Mobile WebKit E2Eをrelease workflowで実行する。
- 待機中の一時切断では席を60秒予約し、同じtokenで同席へ復帰する。
- オンライン対戦終了後は全humanの同意で、同じroom設定の次世代対戦を開始する。
- 対戦開始からの構造化log件数を固定サイズで保存し、再開・再接続・Undo後も引き継ぐ。
- 5人以上では手番・自分を区別したプレイヤー盤面移動ナビを表示する。
- 待機室hostは開始前に自分以外の参加者を確認付きで外せる。
- Service Workerの旧世代から新世代への待機・適用・cache移行を実WebKitで検証する。

現時点でdeferred:

- CPUの本当の評価理由。将来は各decision planからUI専用reason codeまたはscore breakdownを返し、canonical action payloadやonline wireへ混ぜない。
- 収支額・妨害対象・コイン推移の完全な時系列。現在実装した固定サイズ集計は構造化log種別ごとの件数であり、個別transaction履歴は保存しない。

オンライン再戦では `gameGeneration` と再戦専用eventを追加した。ゲームルールと決定論は変更せず、旧世代actionは受信境界で破棄する。
