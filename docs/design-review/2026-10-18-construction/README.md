# 通常施設の建設通知

2人の制御fixtureから実ボタンでサイコロ→建設フェーズ→麦畑購入→市場を閉じて撮影。各幅別の実出目はランダムなので収支/残高は一致しない。自然対局の完走画像とは区別する。

- notice-obscured-320.png: 初案。新通知はDOM上visibleでも、開いた既存収支に隠れて読めなかった。
- notice-art-hidden-320.png: 被覆修正後も共通CSSのdisplay:noneでアートが描かれなかった中間版。
- facility-construction-*.png: SVG表示解除を含む最終版。 実際に新通知を表示する購入時だけ収支を畳む修正後。データと再表示は維持。通知は1200ms、入力透過、追加のゲーム待機なし。入り180msのアニメーション直後に撮影しており、静止した最終フレームの保証ではない。

4幅の1ケースで通知の内容/アート/費用/画面内/文字とアート中心のpaint順/購入後正本不変を確認。購入Undo/テーマ往復/Reduced Motion/保存再開の既存ケースも確認。画像の目視判定とテスト成功は別に記録する。
