# 実卓向きカード卓の画面証拠

- `before-390-grown.png` / `before-1440-grown.png`: 同Goal途中の列配置。縦余白/左右スポークによる縮小を発見した比較元。mainの画像ではない。
- `final-{width}-*.png`: 画面比に応じた最終列配置のブラウザ画像。4人序盤/所有増加/18種類終盤/正面精読。固定状態fixtureで、自然進行の実対局とは別。
- `cardboard-winner-*.png` / geometry: 最終勝利fixture。完成ランドマーク先頭・スクロール説明、320も2列。実対局とは別の固定状態。
- `facility-chain-*` / `dice-final-*`: 実ロールの時系列演出テスト中の撮影。一部はアニメーションの観察時点を固定しており、自然速度で人間が遊んだ記録ではない。

各版の成功/未検証と実対局の出典は[進捗記録](../../ORIENTED-CARD-TABLE-PROGRESS.md)を参照。Android上の自動Chromiumは物理スマホの人間実機テストではない。公式画像や動画はアプリ資産へ複製していない。

`card-table-2-grown.png` は2人18種類fixture、`card-table-2-cpu-dock.png` は通常起動したCPU2人戦の初期通知表示。新しい2人専用列配置と通知移設の確認であり、この2枚を自然な対局完走の証拠とはしない。
