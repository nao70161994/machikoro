# 勝利カードコレクションの実画面

自動Chromium、320×720 / 390×844 / 844×390 / 1440×900。物理スマホではない。

18種類を各2枚（36枚）、有効ランドマーク6完成の固定状態で勝利画面を描画し、麦畑の詳細を実クリック→Escapeで閉じ→元カードへフォーカス復帰した後に撮影。青い枠はフォーカスで、過去の発動再演ではない。固定状態を自然な完走対局とは扱わない。

4幅のbrowser caseは50.5秒で全成功。再戦ボタン下端が各viewport.height内、横はみ出しなし、施設18種類・完成6、景観なし、詳細/フォーカス、高コントラストの勝者黄/他プレイヤー白を確認。

独立レビューの初回は844/1440の再戦が長い右collectionに引かれて画面外に押されるため不承認。左の勝利情報と全操作を単一summaryセルへまとめて修正後、4枚を再レビューした。844の再戦はy255〜302、1440はy381〜430へ移り、重大な操作問題は解消。全種類/末尾ランドマークと名前の表示も目視済み。

残る差：長い所有一覧はページ全体を縦にスクロールする。横持ちのタイトル復帰は少し下だが主要再戦は初期画面内。長名は自然に複数行へ折り返す。右一覧が長い場合は左操作下に余白が残る。カードを読めなく縮小して一覧を画面へ押し込むことはしない。

旧勝利画面は ../2026-10-16-card-table-readability/natural-844-winner.png 等を参照。同一対局の前後ではないので画面状態の違いを含む。
