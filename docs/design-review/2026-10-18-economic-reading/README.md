# 正面閲覧の経済効果と幅変更

全38施設を所有する制御fixture。390pxで自席を正面表示した後、320→390→844×390→1440へ変更して撮影した。新規画面での初期構図や自然対局の証拠とは区別する。

カードnative160×124px、アート高さ62pxを維持し、正面中のみ経済効果を16px帯へ表示。出版社の対人徴収とドリンク工場の銀行収入を区別する。発動中は基本効果より確定した実収支を優先する。

変更前は幅変更で旧world座標を保持したため、配置再計算後に閲覧先から視点が逸脱した。変更後は可視カードのidentityを保持し、そのカードを新viewport中心へ合わせる。倍率・角度・戻る履歴・ゲーム状態は変更しない。大きい施設集合の周囲が切れることは残り、移動と全体復帰を併用する。
