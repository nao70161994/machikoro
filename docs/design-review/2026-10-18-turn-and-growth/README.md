# 成長比較と施設・送金の順序

制御fixtureの4幅grown/lateと10人844、実ルールで4人の森林が発動した画像。自然完走・物理端末とは区別する。

- HUDへ実所有総枚数を追加。スマホは名前横、広い席は残高と目標の間。席の実幅160px以下では語を省略しコインiconを使う。残高16px/目標11pxと44px高を維持。
- 施設紹介と送金はowner+施設の初出順、700ms間隔に統一。出目確定から500ms後に最初の施設を開始し、元カードも同じleadを使う。4施設のCSS/WAAPI delayは500/1200/1900/2600ms。
- 画像のdice-final-confirmationは既存テストで該当CSSアニメーションを一時停止したフレーム。自然な時系列の動画や撮影時刻の証明とは扱わない。
- facility-chain-live-step-2/3/4とlive-activation-tagは実時間で各施設紹介を待って撮影し、アニメーションや時計を変更していない。撮影の遅延はあるため700ms間隔の動画そのものとは扱わない。
- 実発動のタグ生成順、実施設/所有者強調、送金delay、正本不変、再描画/テーマ復帰/Reduced Motionを操作テストで別途確認する。

比較元は前段階のcard-table-experience画像と公式PV。施設カードの構成・ルール・操作経路を変えず、成長比較と因果の読み取りを補う。

飛行中のstep4はbrowser内requestAnimationFrameで開始後180ms以降を観測してから撮影。sample.jsonの観測値は183.28ms/opacity1/銀行→街4で、スクリーンショットそのものの正確な撮影時刻ではない。画像で実際の1コイン・経路・右席施設の対応を確認した。


## CI候補と自然対局

CI39124580958（製品79d2c0d3）の基準候補4枚を別担当が旧画像と比較し採用可。baseline-hud-diff.jsonは変更pixel範囲がHUDのみである記録。他12枚はbyte-identical。

ui-portrait/landscapeの画像とsummaryは同版の無seed実UI対局。人間席の行動はCPU助言で選択するが、状態へ直接適用せず実ボタン/キーボードで操作した。速度100msは実設定UIで選択。物理スマホ・初見人間ではない。勝利画像はfull-pageで、viewport内全カード同時表示の証拠ではない。
