# ダイスシティ 利用ガイド

このガイドは、Webブラウザで遊ぶプレイヤー向けです。初めて遊ぶときは、タイトル画面から対戦人数と参加方法を選びます。

## 画面デザイン

タイトル画面の「画面デザイン」で「クラシック」または「夕暮れの街」を選べます。変更は見た目だけに反映され、ゲームルールやオンライン対戦の状態は変わりません。選択は同じブラウザに保存され、あとから切り替えられます。

## ローカル対戦とCPU対戦

1. タイトル画面で「ローカル」を選びます。
2. 参加人数と各席の人間／CPUを設定し、「ゲーム開始」を押します。
3. 表示された案内を確認し、対戦を始めます。
4. 自分の手番ではサイコロを振り、必要な選択を行ったあと、施設またはランドマークを建設するかターンを終了します。

建設直後に取り消せる状態では「建設を取り消す」を使えます。相手に共有済みのオンライン操作は、ローカル対戦と異なる同期条件が適用されます。画面に表示された確認を読んで操作してください。

## オンライン対戦

1. 全員が同じ公開サーバーのURLを開きます。オンライン対戦は、ブラウザだけでなく接続可能なサーバーを必要とします。
2. ホストは「オンライン」から部屋を作成し、表示されたルームIDを参加者へ伝えます。
3. 参加者は「参加」画面へルームIDを入力します。
4. 全員が準備完了にすると対戦が始まります。ホスト側ブラウザがゲーム進行とCPU手番を中継します。

接続が切れたときは、タイトル画面の「再接続する」から同じブラウザで復帰してください。オンライン再接続データの削除を選ぶと、その端末に保存した復帰情報を消去し、待機室から退出します。進行中の対戦を再接続できなくなる場合があります。

## 保存とアプリへの追加

ローカル対戦の進行は同じブラウザの保存領域に記録され、タイトル画面から再開できます。ブラウザのデータ消去、プライベートブラウズ、別のブラウザや端末への移行では復元できません。オンライン対戦はローカル対戦のセーブデータとして保存されません。

対応ブラウザでは、ブラウザのメニューからホーム画面へ追加できます。インストール表示や更新方法はブラウザと端末によって異なります。ゲーム中は更新案内を保留し、タイトルへ戻ったあとに適用します。オンライン対戦中は更新操作が無効になります。

## 困ったとき

- オンライン部屋へ入れない場合は、ルームID、サーバーへの接続、全員の準備状態を確認してください。
- 再接続できない場合は、元のブラウザでタイトル画面を開き直してください。復帰情報を削除すると、その部屋への復帰情報も失われます。
- 画面の更新案内がゲーム中に表示された場合は、対戦を終えるかタイトル画面へ戻ってから更新してください。

公開するサーバーURL、対応ブラウザと端末、問い合わせ先は、公開環境が確定した時点でこのガイドへ追記します。
