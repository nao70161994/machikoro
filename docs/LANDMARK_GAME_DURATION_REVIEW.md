# ランドマーク数別の対局時間レビュー

2026-09-30 に、基本4種と全6種のランドマーク構成をCPU自己対戦で比較した。初期レビューにあった「全6種の方が約3割長い」という推定を、人数とCPU構成を変えて確認するための軽量な追試。

## 方法

- 各条件50戦、seed開始値7301。同じseed列を4種と6種で使い、各シリーズで席順をローテーション。
- 4種は「駅・ショッピングモール・遊園地・電波塔」。6種はここへ「港・空港」を加えたもの。
- CPU構成は2人/4人、普通CPUのみ/普通と強CPUの混在の4通り。
- `scripts/selfplay.js` の `runSeries` を `lightweightCpuOnly: true`, `lite: true` で実行。ターン数は1ゲームあたりの平均・中央値・90パーセンタイルを記録。
- 差は同seed・同席順の「6種 − 4種」。95%区間は対応差の平均を3000回再標本化したパーセンタイル区間（再標本化seed 9147）。

## 結果

| 対戦条件 | 4種 平均 / 中央値 / 90%点 | 6種 平均 / 中央値 / 90%点 | 平均差 (95%区間) |
|---|---:|---:|---:|
| 2人・普通 vs 普通 | 60.08 / 59 / 73 | 60.28 / 58 / 73 | +0.20 (−3.22〜+3.60) |
| 2人・普通 vs 強 | 61.94 / 62 / 76 | 63.34 / 61 / 82 | +1.40 (−3.88〜+6.56) |
| 4人・普通のみ | 88.60 / 90 / 104 | 94.12 / 95 / 112 | +5.52 (+1.52〜+9.54) |
| 4人・普通2人 + 強2人 | 84.14 / 83 / 95 | 81.76 / 81 / 95 | −2.38 (−5.56〜+0.96) |

全条件で上限打ち切りは0戦だった。

## 判断

6種が常に長くなるとは言えない。4人の普通CPU同士では今回の標本で5.52ターン長かった一方、他の3条件では95%区間が0をまたいだ。4人の混合戦は点推定も逆向きだった。したがって、このデータだけで初期設定を4種へ変えない。

これは軽量モードのCPU自己対戦であり、人間の選択や遊びやすさを測っていない。また、各条件50戦は粗い比較で、勝者の偏りやseed集合に影響されうる。既定数を変える判断には、追加seedでの再現と人間同士/CPU混在の実プレイ感を確認する必要がある。
