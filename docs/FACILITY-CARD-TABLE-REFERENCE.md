## 公式静止画で観察できた構造

| 観点 | 観察 | ダイスシティの設計への意味 |
| --- | --- | --- |
| 盤面 | 一枚の丸い卓面。中央市場と四辺の所有カード列が同じ連続面に載る | 独立した景観枠の集合から、卓の上にカード群が広がる構造へ移す |
| 所有物 | 手前、奥、左右に施設カードとランドマーク。複数所有はカード上部の `×2` 等 | 全員の所有施設を主盤面のカード面で比較する。施設総数や建物絵だけで代用しない |
| 市場 | 中央の複数列グリッド。カード面の色、アート、出目、価格、収益記号が見える。SOLD OUT表示もある | 自分の施設と市場でカード文法を共通にし、購入候補と所有物を視覚的に結びつける |
| HUD | アバター、名前、残高、手番、リーチ等は画面端。施設カードをHUDの詳細に閉じ込めない | 常時情報を端へ集約し、主盤面をカードに割り当てる |
| サイコロ | 任天堂の静止画では中央に立体サイコロと大きな合計4。周辺の所有カードは残る | イベントを卓上の独立レイヤーに置き、誰の場が関係するかを見失わせない |
| 手番 | series_02では大きな「あなたのターンです」表示と自分のHUD強調 | 色だけでなく文字と選択強調で手番を示す。静止画から表示時間は判断できない |
| 完成 | series_01はランドマーク黄金発光、紙吹雪、祝賀モチーフ、4/4の大表示 | 通常購入と勝利につながる完成を強弱で区別する。素材やキャラクターそのものを複製しない |
| 向き | 奥のカードは倒立、左右は90度回転。手前は正立 | 同卓感は参考になるが、タッチ画面の精読性まで劣化させる必要はない。正立カード＋座席位置でも同卓感を出せる |

公式画像でも遠い列の名前は小さく、演出中の中央は一時的に隠れる。参考作品のあらゆる文字が常時精読可能という主張はしない。常時一覧で施設の色・絵・出目・枚数を把握し、必要なカードを自然に拡大できる二段階の読み取りを目標とする。

## 現mainとの具体的な差

目視した比較画像: `docs/design-review/2026-10-14-shared-plaza/1440-overview-grown.png` と `844-overview-grown.png`。

- mainは四つの独立した角丸枠に街の景観を描き、中央だけが施設カードになっている。全員の施設種別・色・出目を同じ記号体系で比べられない。
- 景観から建物が増えたことは分かるが、たとえば「出目5の青施設を何枚所有しているか」はカード卓を開く追加操作が要る。これはユーザーの主目的に合わない。
- PCでは大きな景観の空、道路、地面が面積を取り、市場は縦長の中央欄に限定される。横持ちでは市場カード2枚程度と景観4枠になり、カードゲームとしての主役が分散する。
- HUDは読みやすいが、独立枠と市場欄によってWebの情報パネルとして見える。カード群を同じ卓面へ並べ、所有者の境界を座席名・色帯・余白で表すことが必要。
- 既存の施設アートは市場で大きく識別できるため再利用できる。景観描画の拡大が今回の改善ではない。

## 実装判断と検証条件

1. 2〜4人の通常主盤面は、全員の所有カード群と中央市場を同じ卓に置く。選択した一人の施設だけに切り替わる表示を主表示にしない。
2. 一覧カードに最低限、施設名・施設アート・分類色・出目・所有枚数を持たせる。休業/発動はカードの状態として区別する。タイトルだけのラベルや建物の羅列へ縮退させない。
3. 盤面が広い場合はユーザーがパン・スクロール・拡大縮小できる。初期の全体把握と、読みたいカードを読む拡大を両立させ、全カードを小さく固定して操作性を犠牲にしない。
4. 所有枚数・施設種類が増えた終盤でもカードの存在が失われないよう、同一施設は枚数でまとめ、カード群の必要面積は盤面側で確保する。カードを詳細欄にだけ隠す実装は不適合。
5. 市場購入、カード詳細、特殊選択は既存ルールの正本を参照する。パン操作とカードタップが競合しないか、フォーカス/キーボード/Reduced Motionも確認する。
6. サイコロ確定→施設発動→残高変化→購入→ランドマーク→勝利を時系列で観察する。静止画だけで連鎖の分かりやすさ、演出テンポ、コイン移動の理解を合格にしない。
7. 参考はSwitch/PCの最大4人画面。スマホ320pxや5〜10人への自然な配置は参考のコピーでは証明できず、ダイスシティ自身の実画面と操作で別途確かめる。

## 未検証と推論の境界

この文書で、参考作品の操作応答、ズームの有無、カード選択方法、アニメーション時間、収益連鎖順、音声を体験したとは主張しない。動画ファイルの取得成功も、その映像を再生して研究済みである証拠ではない。比較後の製品品質は、変更後の実画面を参考画像と並べ、実際の進行を操作し、独立レビューで判定する必要がある。


## 公式PVの再生フレームによる観察

ブラウザのvideo要素で480p映像を読み込み、8/20/35/50/65/80/95/110/122秒と68〜88秒の1秒間隔をseekして描画したフレームを目視した。研究用PNGはartifacts/reference-card-table/framesに保存し、出荷資産には含めない。参考作品を操作した検証ではなく、音声も取得していない。編集されたPVであるため、フレーム間の対局進行を連続した実時間の操作応答とは解釈しない。

- 65秒：全員の初期カードと中央市場が同じ卓面に残り、開始告知だけが中央に重なる。
- 70/72/74秒：サイコロが市場上に独立して描かれ、残像を伴う大きな動きと通常の卓面を切り替える。所有カードは盤面から撤去されない。
- 76秒：コインの光る列とHUD側の強調で収益の獲得を示す。静止フレームだけで各移動の厳密な始点・順番は断定しない。
- 80/82秒：ランドマークのカード面が中央に大きく浮き、名称・コスト・効果を読める。背景の卓と全員のカードは暗くしつつ残す。
- 86秒：完成カードと4/4の達成表示、紙吹雪等で通常手番と勝利を明確に区別する。

ダイスシティでは一枚の卓、カードの共通文法、操作を保つイベントレイヤーを採用し、参考のキャラクターやアート、祝賀モチーフをそのまま複製しない。現段階のプロトタイプは全員の所有施設を同じ卓面に載せてパン/ズーム可能にしているが、HUD・カメラ初期位置・読みやすさ・イベントは実画面で改善中。完成扱いではない。
