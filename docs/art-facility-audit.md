# 施設アート全38枚の監査

## 方針と証拠

2026-10-04の美術改善。既存の夕暮れ、濃い輪郭、クリームの壁、青緑の屋根という画風を維持し、施設ごとに仕事の痕跡、前景、街路への接続、窓や入口からの光を描く。細かい線を全画面へ一様に増やすことや、共通filter、viewBox変更だけでは改善としない。

元の1440px実画像は `artifacts/premium-design/art-direction1440/sunset-market-gallery-{1,2,3}.png`。第一展開後の実画像比較はroot担当が順次取得する。下表はsource監査と実装判断を記録し、最終画像再レビューの代わりにはしない。

31施設を個別改善し、7施設は既に構図差と仕事／生活の場面が成立しているため維持した。維持も全38施設の監査に含むが、描き直した枚数として数えない。ランドマーク6種はこの38枚とは別の監査対象。

## 技術上の確認

- SVG XMLのparse、ID重複なし、`url(#...)`塗り参照の解決を確認。
- `node tests/facility-art.test.js` 成功。38施設が固有の同梱symbolを参照する既存検査を維持。
- 新規のraster画像、外部font、filter、常時animationなし。追加図版は静的geometry。
- spriteは約139KB。変更後の実描画、配布サイズ、狭いカード内の識別性はrootの実ブラウザ比較で確認する。
