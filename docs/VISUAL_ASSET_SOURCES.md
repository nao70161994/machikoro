# ビジュアル資産の出所

この記録は図版の制作元を記録するものであり、ゲーム全体の販売許諾を証明するものではない。

| 資産 | 制作元・方法 | 外部素材 | 状態 |
| --- | --- | --- | --- |
| `icons/sunset-city.svg` | 本リポジトリの新版タイトル用に、住宅・商店・時計塔・街路・サイコロをSVGの図形として新規記述（2026-09-25） | 外部画像・フォントファイルの埋め込みなし | 実ブラウザで表示確認済み |
| `icons/facility-art.svg` | `scripts/create-facility-art.py` に記述した独自の幾何図形から生成（2026-09-25）。農園・牧場・森林・鉱山・商店・工場・漁船・公共施設・汎用ランドマークの9種に、駅・商業施設・観覧車・電波塔・港・空港の専用図版6種を追加（2026-09-26） | 外部素材なし | 新版の建設メニューで表示確認済み。施設個別の絵は今後拡充 |
| `icons/icon-192.png`, `icons/icon-512.png` | `create-icons.js` に生成処理あり | 既存資産の制作履歴・使用条件は別途確認が必要 | 未確認 |
| 既存の絵文字 | OS/ブラウザの絵文字フォントで表示 | 外部フォントファイルは配布していない | 独自アイコンへの置換範囲を検討中 |
| `js/citySkyline.js` の街並み | Canvas図形で描画する既存コード | 制作履歴・使用条件は別途確認が必要 | 未確認 |

## 販売前に残る確認

- タイトル、カード名、カード説明、ルール説明の出所と販売利用条件。
- 依存ライブラリのライセンスと必要な表示。
- 配布先の確定後、その配布物に含まれるフォント・図版の一覧と使用条件。
- 今後追加する図版はこの表に制作元・外部素材・検証状態を追加する。
