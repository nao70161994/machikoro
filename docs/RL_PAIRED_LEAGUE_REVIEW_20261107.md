# RLリーグ戦：席順を考慮した統計再検証

対象：[13組のリーグ戦 run 42310329077](https://github.com/nao70161994/machikoro/actions/runs/42310329077)。
再検証：[pair bootstrap run 42313844141](https://github.com/nao70161994/machikoro/actions/runs/42313844141)。

## 改善内容

- 従来の「総勝率と独立試行のWilson区間」だけで優位を判定せず、各lineupで利用可能なpaired-seat bootstrapの95%区間を使用する。
- 乱数条件ごとに席順を回したブロックを再標本化するので、席順を無視した95%区間よりも慎重な判断ができる。
- 4人戦では相手CPU構成ごとの区間が**すべて**同じ側を支持する場合にのみ、その方向の優位と呼ぶ。
- 各席の対局数が均等か、ゲーム途中打ち切りや重複ペアが存在しないか検証し、問題があれば集計を中断する。
- 13組の多重比較補正は未適用。以下は探索的結果であり「採用決定」と同義ではない。

## 主要な差分

| 直接比較 | 勝–負 | ブートストラップ95%区間 | 判定 |

| 4人戦seed145 → seed104 | 40–82 | 1構成が50%をまたぐ | 判定保留 |

従来の単純な2人戦seed73対seed76のWilson区間は50%をわずかに超えていたが、paired bootstrapの下限は50%未満となった。局面の共通性と座席差を考慮し、短いリーグ戦では強さを断定しない。

## 今後の方針

- seed73/seed76は購入カードの分布差が大きく、複数採用を維持する。
- 新モデルの昇格は本集計だけでなく、未使用乱数による直接対決、安定した相手CPU構成、特殊行動と保存復元の互換性検証を必須にする。
- 次の反復では、各主要ペアの対局数とpaired bootstrapの反復数を増やし、多重比較補正を入れる。
