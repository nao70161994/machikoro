## 品質判断と限界

全員のカードを同じ卓で比較する構造と正立アートを維持し、固定UI、所有量に応じた配置、確認前への復帰、実カード上の収益対応を改善した。終盤の全体図では細字の精読に拡大が必要だが、拡大後は所有者見出し、施設名、出目、枚数を即座に読める。最後の320/390全体/拡大4枚の独立レビューで、細帯・残高/目標切れは解消し、新しい重大な重なり・欠落・ボタン切れは見つからなかった。

最終版feの自然進行5フレームでは、振る→出目1→席1の麦畑+1→席2の麦畑+1→通常卓への復帰を観測した。実撮影時刻は809/1545/2210/2685/3329msで、精密な時間測定ではない。この5枚では飛行中のコインは確認できなかった。別の実出目診断では銀行→プレイヤーの1コイン飛行を実際に発生させ、アニメーションだけ700msで停止して撮影した。撮影前後のゲーム状態は一致するが、停止画像は自然な時間進行の証明には使わない。

Release CIの全7ジョブ、縦横の自然UI完走2ジョブ、最終基準候補生成が成功した。旧基準とのvisual reviewは、変更対象のにぎわい4枚だけが不一致で、他12テーマ画像・タイトル6件・広場イベント/操作28件は成功。4枚は実装者と別担当が目視し、最終証拠コミットで更新する。製品コードはfe668754から変更していない。

公式との比較は同ディレクトリのcompare.htmlで並べて確認できる。公式画像は外部参照で、配布資産へ複製しない。

公式作品の立体カメラ、サイコロの質感、音を含めた演出の豊かさ、初見の物理スマホユーザーの理解速度まで同等と保証する証拠はない。参考作品を実際に操作した評価でもない。これらの限界を自動ブラウザ成功で置き換えず、Release CI成功・同一製品版の実対局・画像の結果を確認して完了を判断する。

### 実画像による評価と残差

共通卓・全所有施設・市場という画面構造、正立アート・分類色・出目・枚数、固定HUD削減、読み取り倍率への移動/直前復帰は目標に沿う。独立比較で見つかった価格/収入の曖昧さも『建設Nコイン』で解消した。勝利時も実所有カードを主役にし、長いcollectionから左の再戦操作を分離。縦横の自然対局画像で中終盤のアート欠落・所有者欄への侵入・再戦押し下げは発見されなかった。

最新自然横の時系列5枚は、rolling→確定6→非発動という正しい例。所有が麦畑/パン屋だけなので、この5枚から発動タグ/送金flightを確認したとはしない。自然終盤では発動1/2/3と純収支、下部の6+4の実面を目視。制御した新ロールの全所有者タグ/再生安全性は同版CI、1/2面のpipとタグの精密画像は同じ演出コードの既存検証で確認する。cardBoardField.js/cardBoardActivationTags.jsはfe版以降無変更だが、旧自然撮影と最新自然撮影の結果は分ける。停止したコイン診断画像は自然時間の証明ではない。

終盤全体図は精読に拡大が必要。公式の立体カメラ・キャラクター表現・音を含む資産量には差があり、初見の実機ユーザーが同じ楽しさ/操作負荷と感じることまで証明していない。ゲームを一望し必要なカードを読む2D卓としての改善と、参考作品への完全な主観的同等性は分けて評価する。これらの差を伏せてテスト成功だけで商用同等とは断定しない。
