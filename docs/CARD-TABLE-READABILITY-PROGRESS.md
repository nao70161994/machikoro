## 今回の課題と方針

既存REFERENCEの公式実画面/PVと、前版の実対局画像を再利用して比較する。全員のカード卓を維持し、見えないほど縮小して全情報を押し込む状態を改善する。景観/一人専用情報パネルへの回帰はしない。

1. 固定UI: 終了/ログ/比較/倍率設定を一つのメニューへ。手番の重複表示は下部へ移し、広い画面ではロスター・主な卓操作・メニューを一行へ、縦持ちは二行へ。
2. PC: 所有種類数に応じた2〜6列・左右所有/中央市場の配置へ。序盤の空き列と上下の空き行を減らし、カード本体126pxを維持して表示倍率を上げる。
3. 読み取り: ポインタ基準zoom、2指pinch、1指native pan、一時確認前の倍率/位置へ戻るAPIとボタン。自由表示中のresizeも盤面中心を保持。
4. イベント: 縮小された実カードに、施設名/席番号/純収支を14px程度の画面座標タグで付ける。700msの紹介順、同時1枚、画面外は出さず、scroll/resize/新結果/replay境界で破棄。CPU待機/自動panは追加しない。

- 比較/ログ/終了の既存ID/actionは維持し、倍率メニューも同じcamera commandへ接続。
