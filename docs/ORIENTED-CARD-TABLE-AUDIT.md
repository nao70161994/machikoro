# 実卓向きカード卓の比較評価

基準main:205be605。実装/検証の正確な版と状態は[進捗記録](ORIENTED-CARD-TABLE-PROGRESS.md)。公式と同等以上という断定ではなく、改善と検証限界の記録である。最終CI/同版実対局の結果は[PR16のChecksと本文](https://github.com/nao70161994/machikoro/pull/16)を参照。

## 公式との比較

公式資料と観察範囲は[参照分析](ORIENTED-CARD-TABLE-REFERENCE.md)。公式作品をこちらの端末で実操作した比較ではなく、公式静止画/PVと自作ゲームの実ブラウザ比較である。

| 観点 | 今回の改善 | 残る差・検証限界 |
| --- | --- | --- |
| 共通の卓 | 手前0°/奥180°/左90°/右270°で中央市場を囲む。ランドマークも同じ席方向 | 公式の俯瞰3Dカメラと異なり、ブラウザの2D紙カード卓 |
| カードの存在感 | 既存アートを160×124の統一書式へ。旧密度別上書きを整理し、席方向を含む実寸で配置 | スマホ全体表示では全施設名の精読は困難。全体比較と拡大精読を使い分ける |
| 閲覧 | 対象席/カードを逆回転して正立、直前の角度/中心/倍率へ戻る | 公式PVから任意席カメラ操作の詳細は断定できない。自作の操作はブラウザで検証 |
| 余白 | 浅い横持ち/PC/縦持ちで左右席の列数と市場幅を変える | 5〜10人や全員が多数種類所有する状態は倍率が下がる。隠す/消す解決はしない |
| 発動・収益 | 実カード上に所有者名/金額/連鎖順。出目確定と送金は既存演出を再利用し、幾何更新時の欠落/誤位置を修正 | 3D物理ダイス、音とカメラの高度な同期、公式の豊富なキャラクター表情との違いは残る |
| 勝利 | 枚数/種類の達成表示、完成ランドマークを先に、全施設は詳細閲覧可能。勝利時の旧手番告知を即終了。小幅も2列、PCは一覧と再戦を近く保持 | 多種類の全カードはスクロールが必要。物理端末や初見ユーザーによる操作評価は未実施 |
| 互換性 | 表示専用layout/camera。GameManager/server/カード定義/save形式は変更しない | 最終版の混在オンライン/再接続/Undo/完走/CI確認結果は進捗へ追記予定 |

公式と同等以上の主観的品質を、テスト成功や回数だけで証明することはできない。現時点で同等以上と断言しない。特に多人数終盤の全体倍率、演出の立体感、初見での拡大操作の理解、物理スマホの操作感は評価の限界として残す。
