# 多面的レビューの進行記録（2026-10-05）

## 目的と終了条件

保守性・責務分離、デザイン・操作・アクセシビリティ、ルール・CPU/RL、オンライン・復元、保存・PWA、依存関係・セキュリティ、テスト・CI・文書を対象に、レビューと修正、検証、担当以外の再レビューを繰り返す。
全領域をカバーした最終一巡で新しい具体的な対応可能な指摘がなく、既出指摘が解消または根拠付きで修正不要と判断され、必要な検証が成功した時点で終了する。テスト成功だけを全体レビュー完了とは扱わない。

## 対応した具体的指摘

| 分野 | 問題 | 対応・回帰確認 |
| --- | --- | --- |
| 保存 | 不正な旧世代の選択で有効な保存も削除する | 世代ごとに失敗を扱い、有効な旧世代を維持する |
| 保存 | 同じ状態の再保存や書き込み失敗で復旧履歴を消費する | 最新保存の成功・状態変更時だけ旧世代を更新する |
| 復旧UI | 最新保存の欠落・破損で有効な履歴も再開できない | 有効な世代だけを提示し、最初の有効世代を選択する。孤立shadowは再開しない |
| 再開始 | 再開始で旧履歴が残り、終了した対局が再開候補になる | 確認後に最新・shadow・履歴をすべて削除する |
| オンライン | 待機中ホストの予約失効後、部屋を操作できるホストがいない | GC・参加・再参加時に接続中プレイヤーへホストを移す。開始済み対局と未失効予約は維持する |
| 広場操作 | 場外でポインターを離してもパンが続く | window上の終了・cancel・blurとcapture喪失を処理する |
| アクセシビリティ | 広場でフォーカスした市場カードが画面外に隠れる | 市場スクロールとカメラを調整し、resize後も対象を表示する。進行中のポインター操作は維持する |
| 非同期開始 | 遅いRL preloadが後続のクイック開始や他画面遷移を上書きする | 開始世代を管理し、成功・失敗とも古いcallbackを破棄する |
| オンライン開始 | 遅いRL作成preloadが後続の部屋参加・resetを上書きする | ロビー要求世代をモデル読み込みにも適用する |

## 証拠と残りの確認

- 保存・再開始・ホスト失効は担当以外が再レビューした。CPU/RL、SW/PWA、公開ファイル制限・CSP、APK/CIと主要運用文書もレビューした。
- Chromiumで場外release、通常focusによる全44施設・ランドマークの表示、1440→390幅変更を確認した。
- 390px・1440pxの通常ブラウザ確認ではテーマ切替、開始、オンライン作成・参加、建設・Undo、ホストrefresh/rejoin、結果・共有画像を確認した。
- npm audit: 0件。RL registry、APK/TWA静的検証、静的解析、最新修正後の `npm test`、オンライン再接続E2Eは成功した。PWA実ブラウザ確認で対局中の更新保留・終了後の更新と再読み込み・旧cache削除・オフライン起動も成功した。
- 証拠ログ・キャプチャは `artifacts/multifacet-review/` に保存する（生成物）。
- **進行中**: 最新状態での全領域最終一巡、最新pending画面の確認、WebKit CI。WebKitはこのTermux環境で実行できないためCIで検証する。
- サブエージェント利用上限で一部再レビューが一時停止した。オンライン非同期修正の独立再レビューは再開後に通過した。人間への実機確認依頼はしない。終了条件はまだ満たしていない。
