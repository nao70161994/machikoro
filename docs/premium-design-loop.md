# デザイン仕上げのレビューループ

## 目標

夕暮れの街・ダイス・カード・成長する街を作品の軸にし、フルプライス商品に近づける見た目と視覚体験を実装する。採点やレビュー回数だけを成果にしない。実画面の比較、操作検証、独立した再レビューで判断する。

## 担当と検証

- アート担当：ロゴ・文字・カード構図。
- 盤面担当：PC／スマホの街・操作・市場と情報階層。
- 状態担当：特殊効果・結果・オンライン待機／復旧・遷移。
- 統合担当：実ブラウザ、メモリ監視、CSS統合、回帰検証、コミット／Push。

ブラウザは重ねて起動しない。320／390／1440px、両テーマ、序盤／終盤、多人数・長い名称、pending、オンライン復旧、Reduced Motionを確認する。改善後の担当交代レビューを2巡実施し、新しい対応事項が出たら再び実装する。

## 第1巡：具体的な欠点と実装

|欠点|実装|検証状態|
|---|---|---|
|PCの専用操作列が大きな空白を作り、市場の通常名まで折り返す|街を左、横長操作帯と5〜6列市場を右へ再構成|1440実画像で市場6列・通常名の視認性改善を確認。開始・建設・Undo・再接続・勝利の実操作フロー成功|
|清掃・改装の選択が文字だけで通常カードと画風が途切れる|施設アート・名前・作用を一体化した選択カード|関連単体・320/390/1440実画面確認成功|
|代表カードが中央正面の建物という同じ構図に偏る|牧場の前景牛、鉱山の坑道遠近、寿司屋の店内、空港の前景飛行機。旧crop解除|SVG・関連単体成功、全38施設・6ランドマークのgallery確認済み|

実画面で操作ボタンが縦180pxへ膨らむ統合漏れを発見し、横方向flexを明示して修正した。旧smokeのオンライン速度設定は外側の詳細設定を開かずに寸法を検証していたため、実際の階層を開いてから検証するよう修正した。

## 評価対象（最終監査は末尾）

- 特殊効果の全種を実画面で比較。引越し屋の文字selectを含めた一貫性。
- 序盤／終盤で建物数以外にも発展を感じる街と完成画面のつながり。
- 市場の二重見出し、背景の重なり、場所としての表現。

- オンライン待機の重複名簿と参加席の見せ方、復旧・エラー・空状態。
- スマホの密度・長い名称・多人数・低モーションでの品質。

## 第2・3巡：統合漏れと追加改善

- 空港の前景飛行機の輪郭が欠けていたため修正。
- 買えないカードの影がCSS詳細度で復活し、本文と詳細操作の間に太線を作っていたため除去。購入可能時の同様の下影も除去し、外側カードだけに厚みを残す。
- 320pxの名前を全幅へ、価格を次行へ。複数出目を一まとまりとして保つ。
- 引越し屋も絵付き候補へ統一し、既存resolver用selectと値を同期。CSSがhiddenを上書きする漏れを修正。
- 街の遠景を既存発展段階で丘→住宅→街区へ変化させる。縦長の街で背景が巨大化するsliceをmeetへ修正し、前景施設を主役に保つ。
- 再戦辞退を静かな補助操作へ、市場の重複小見出しは視覚的に省略。
- 待機室の3重名簿を参加席一覧へ整理し、設定を折り畳む。参加後はタイトルを縮約し参加前フォーム／本人への重複再接続案内を隠す。退出時はフォームを復元。

## 第2・3巡時点の検証証拠（最終結果は末尾）

- Chromium 320/390/1440の混在テーマオンライン対戦：開始、出目、市場、建設、authoritative Undo、ホスト再読込復帰、勝利成功。
- 1440 dense勝利街（8施設+6ランドマーク）：はみ出しなし。
- quiet/neighborhood/cityとCleaning/Renovation/Moverを320/390/1440で撮影、横溢れなし。
- 施設アート、UI、pending、room-share、DOM effects、lobby runtime、integrationの関連テスト成功。全unitの初回は旧名簿文言期待1件のみ失敗し、新しい席・空席・CPU・開始条件の期待へ更新してintegration全件成功。
- static/type検査成功。最終全unitとWebKit回帰はCIで確認する。
- 最終実装の独立レビュー2巡と、まだ評価不足の補助画面・Reduced Motion・多人数の追加証拠を継続する。現時点でゴール完了とは扱わない。

証拠：`artifacts/premium-design/iteration2-320`、`iteration2-390`、`iteration2-1440`、`artifacts/product-pwa-browser/20261004-142315-524fa24c`。ギャラリーの撮影用fixtureは下段が切れないようスマホ4枚／ページへ変更した。

### 再レビューと検証ゲート

- 担当を交代した独立再レビューで、カード・盤面・特殊効果・待機・結果を2巡確認。末尾孤立改行とタブ文字越えは修正後の画像で解消を確認。
- CI初回はrelease-testとCPU smokeが成功、WebKitは旧3列期待1件と待機横溢れ6件で失敗。旧期待を実配置とDOM／Tab順へ更新し、横溢れは製品コードで修正した。
- 新街背景のreduce指定は全体の極短duration指定より優先し、遷移を完全停止する。テスト期待を緩めず実測0sを確認。
- 最終コード `d7741975` の [CI run 37181691103](https://github.com/nao70161994/machikoro/actions/runs/37181691103) は全ジョブ成功。WebKit **65件成功、失敗・flakyなし**。release内static／unit／PWA／online sync・reconnect E2E／release E2E、CPU difficulty smokeも成功。
- Native Chromiumの最終Tab実操作は390／1440pxでプレイヤー→操作→市場の順に成功。320／390pxの4タブは全て幅・高さ44px以上、文字範囲も内側。証拠：`artifacts/premium-design/keyboard-check.log`、`final-gates-fit.log`。
- 重要な既知指摘の実装・実画像確認、担当交代による独立再レビュー2巡、関連回帰ゲートを満たした。このコード版についてレビューループを完了する。以下の制約を含めた判断であり、価格相当の普遍的保証ではない。

### 制約

価格に相当する見た目を保証する採点ではなく、具体的な画面改善・可読性・一貫性・回帰結果で評価する。ネイティブChromiumは幅を模擬した自動ブラウザで、物理端末の触覚品質やユーザーの好みを証明するものではない。短い駅-only実対戦の証拠を通常全ランドマーク対局やWebKit／PWA検証の代わりにしない。各検証の対象範囲を分けて記録する。
